Minecraft 建築スタジオ（GitHub Pages用）

ファイル構成
index.html
style.css
app.js

公開手順
1. GitHubで Minecraft という名前の公開リポジトリを作成します。
2. 3ファイルをリポジトリの最上位へアップロードします。
3. Settings → Pages → Deploy from a branch → main / (root) → Save を選択します。
4. 公開先： https://numumac.github.io/Minecraft/

マイポータルへの戻り先は https://numumac.github.io/ に設定済みです。
注意：ブラウザ内保存は端末をまたいで同期されません。バックアップを利用してください。
